## 📂 Featured Projects

<details>
<summary><b>🏦 Bank Customer Churn Prediction & Retention Analytics</b></summary>
<br/>

Analyzed 10,000 bank customer records to understand who churns and why, then built a
model and dashboard to help a retention team act on it — from raw SQL exploration through
a deployed prediction interface.

| | |
|---|---|
| **Stack** | MySQL · Python (Pandas, Scikit-learn) · Power BI · Streamlit |
| **Scale** | 10,000 customer records, 10 engineered features |
| **Performance** | Random Forest classifier — 74% F1-score, 78% recall (tuned to minimize missed at-risk customers) |
| **Security** | Public/synthetic banking dataset — no real customer PII involved |
| **Impact** | Found churned customers hold 24% of total balance despite being only 20% of headcount; compiled findings into a retention playbook and business memo |
| **Repository** | [bank-churn-prediction-analytics](https://github.com/rishibhor326-lgt/bank-churn-prediction-analytics) |

The project runs end-to-end: SQL for data quality and segmentation (gender, geography,
headcount vs. balance), Python for feature engineering and modeling, Power BI for a
Geography/Age/Tenure breakdown of churn, and a Streamlit app so a non-technical user can
get a live churn prediction for a given customer profile.

</details>

| | |
|---|---|

output for ERP import, analyst review, and API consumption respectively.
